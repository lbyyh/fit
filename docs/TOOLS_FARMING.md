# 工具栏与农耕（主地图 · 农场）

> **状态**：✅ 已实现，待 Unity 验证
> **范围**：底部 3 格工具栏 + 锄头 + 种植。**只在主地图农场装配**
> **生成**：菜单 `Fit / 农场 / 生成主地图场景（农场）` 会自动装好，无需手动配置

---

## 1. 底部 3 格

| 格 | 内容 | 左键行为 |
|---|---|---|
| **1** | 武器 | 开火 |
| **2** | 锄头 | 锄地（生地 → 耕地） |
| **3** | 胡萝卜种子 | 在耕地上播种 |

数字键 `1/2/3` 切换，鼠标滚轮循环。选中格放大 + 反白。

**为什么是 3 格**：主地图上玩家同时要做的事就三件 —— 打菜、锄地、播种。
再多会挤占第一人称本就不宽的视野（§5.1 冲突一），而且主地图的农具体系
**不该长成一个完整的经营游戏**，那是另一个玩法循环、另一份工作量。

**为什么武器也占一格**：左键只有一个。让武器和农具走同一套切换，
才能保证"拿着锄头时不会顺带开枪"。

---

## 2. 锄头

- 准星对着菜畦，左键锄出**一格**（1×1 米，网格对齐）
- 冷却 0.35 秒，只响应点按（按住连发会瞬间锄完一整畦，像电动农具）
- 已经是耕地的格子再锄无效

**为什么按网格对齐**：不对齐的话玩家能锄出满地歪歪扭扭的小块，
既不美观也难判定（"我明明对着那块地按的"）。对齐后每格一个状态，
判定简单可预测，视觉也整齐。

---

## 3. 种植与成长

```
生地 --锄头--> 耕地 --种子--> 幼苗 → 长叶 → 结果（各 10 秒）→ 成熟
                                                              ↓
                                                    长出一只胡萝卜兵
                                                    地块退回"已锄"，可再种
```

水壶能让成长加速 2 倍（`ToolKind.WateringCan` 已支持，场景里暂未装配）。

---

## 4. ⚠️ 为什么种菜不产出任何资源

H2 已拍板「主地图蔬菜不掉落资源」，`SCENE_FARM.md §4` 也警告过：
**主地图一旦能稳定产出资源，玩家就会赖在这里种田而不去闯关，核心循环（§2）直接被架空。**

所以作物成熟后长出的是**小怪**，不是资源：

> 锄地 → 播种 → 长出怪 → 打掉 → 再锄

这是个纯整活的闭环 —— 等队友时有事干（ID-004），又刷不到任何东西。

将来真要做农场经营向的产出，那是另一个玩法循环，
必须重新过一遍 §4 的收益评估，不能在这里顺手加。

## 5. 技术要点

| 项 | 做法 |
|---|---|
| **武器与农具统一** | `IHoldable` 接口。锄头没有弹匣 / 伤害 / 后坐力，硬塞进 `WeaponData` 会带一堆不适用字段 |
| **左键归属** | 有 `Hotbar` 时交给它分发；没有则退回直接开火（灰盒测试场景不受影响） |
| **锄地判定** | `RaycastAll` 取最近的一块 `Farmland`，跳过玩家自身 —— 否则低头锄地时先打到自己的 CharacterController |
| **碰撞体** | `Farmland` 自己补一个 BoxCollider（生成器拼零件时会删掉 Collider，不然射线直接穿过去） |
| **手持模型** | 挂在相机下而不是身体上，枪/锄头跟着视角走，转身不拖影 |
| **联机** | 阶段 3 再做。耕地与作物状态由房主权威，玩家操作改 `ServerRpc` |

新增文件：

- `Gameplay/Tools/` — `IHoldable` · `ToolData`(+`CropDef`) · `ToolBase` · `Hotbar`
- `Gameplay/Farming/` — `Farmland`
- `UI/` — `HotbarHud`
