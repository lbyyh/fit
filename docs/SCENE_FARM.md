## 1. 主地图是干什么的

| 功能 | 说明 | 优先级 |
|---|---|---|
| **队伍集合 + 出发** | 1-5 人在这里碰头，组队后从农场出发进闯关 | 必需 |
| **皮肤 / 武器展示** | ⭐ **这是 Q2 决策的关键落地点** —— 第一人称战斗中看不见自己，主地图是唯一能看见全身模型和皮肤的地方 | 必需 |
| **蔬菜小怪热身** | 打打菜园里的蔬菜，练枪法 / 试新武器 / 教新手 | 本次重点 |
| **整活互动** | 骑猪、干草堆、互相推搡，等队友时不无聊 | 高（ID-004） |

**为什么主地图必须有战斗**（而不是纯安全区）：
新手需要一个零压力的地方熟悉射击、翻滚、前摇读招。地牢里第一次遇到弹幕就死，体感很差；
在农场先拿胡萝卜兵练手，成本低得多。这也是"轻松欢乐"基调的一部分。

---

## 2. 场景布局

一张**不大、逛一圈 30 秒**的院子，不做成开放世界：

| 区域 | 内容 | 作用 |
|---|---|---|
| **农舍前院** | 出发门（选关）、信箱（邀请好友） | 集合 + 出发 |
| **菜园** | 3-4 块菜畦，蔬菜小怪在这里刷新 | **战斗区** |
| **谷仓** | 武器架、更衣镜、图鉴板 | 皮肤 / 武器展示 + 更换 |
| **院子** | 干草垛、猪圈、水井、风车 | 整活互动 |
| **篱笆外** | 麦田、远山（纯远景，不可达） | 撑氛围 |

**规模控制**：整体约 60×60 米，玩家跑一圈不超过 30 秒。
主地图的价值在"停留舒适"，不在"大"。

**视觉**：沿用 Q1 低分辨率 3D（640×360）。明亮日光、暖黄麦田 + 草绿菜畦。
**天空刻意降饱和**（淡蓝偏白）—— 天空是弹幕背景，太抢眼会吃掉子弹（§9 可读性）。

## 3. 蔬菜小怪（本次重点）

全部遵守铁律：**有前摇（ID-008，0.4-0.6s）** + **弹幕可预判（§5.1 冲突一）** + **Q 版萌系（ID-006）**。

| 蔬菜 | 造型 | 攻击方式 | 前摇表现 | 威胁 | 备注 |
|---|---|---|---|---|---|
| **胡萝卜兵** | 橙胡萝卜，小短腿，顶着一撮缨子 | 跳起来用头顶撞（近战） | 身体后仰蓄力 0.4s | ★ | **教学用**，最慢最好躲 |
| **番茄投手** | 圆红番茄，两只小手 | 抛番茄弹（慢速，砸地溅汁） | 双手举过头顶 0.5s | ★★ | 唯一远程抛射 |
| **土豆滚雷** | 圆胖土豆，身上有芽眼 | 贴地滚过来撞人，撞墙弹回 | 原地加速旋转 0.4s | ★★ | 弹回时可预判 |
| **玉米粒射手** | 玉米棒，穿着苞叶"外套" | 3 发扇形玉米粒 | 棒身抖动、苞叶张开 0.45s | ★★★ | 首个弹幕型，教读扇形 |
| **洋葱催泪弹** | 紫皮洋葱，一层层 | 靠近后膨胀释放催泪气体（范围） | 膨胀 + 剥皮 0.6s | ★★★ | 范围攻击，前摇**更长**（0.6s） |
| **辣椒冲锋兵** | 细长红辣椒 | 高速直线冲刺，留火焰尾迹 | 全身变红发亮 0.5s | ★★★★ | 最快，考验翻滚无敌帧 |

**难度梯度**：胡萝卜 → 番茄 / 土豆 → 玉米 / 洋葱 → 辣椒。
新手从胡萝卜兵开始，逐步遇到弹幕型（玉米）和高速型（辣椒），**主地图本身就是一张教学曲线**。

### 3.1 战斗强度：刻意温和

| 参数 | 主地图蔬菜 | 地牢敌人 | 原因 |
|---|---|---|---|
| 伤害 | 5-10 | 12-25 | 主地图不该有压力 |
| 血量 | 30-60 | 100 | 几枪就碎，反馈快 |
| 同屏上限 | 5-6 | 5-8 | 略少，保持轻松 |
| **是否会倒地** | **不会** | 会 | 见下 |

**玩家在主地图不会倒地**：蔬菜的伤害带 `DamageFlags.NoDown` 标记（`Health` 已支持），
血量最低保留 1，被"打飞"而不是死亡。枢纽场景里死亡是纯粹的负面体验，没有任何收益。

**刷新**：蔬菜被打碎后 15-20 秒原地重长（从土里冒出来），可以一直练。

## 4. ⚠️ 掉落边界：别让主地图变成"刷子乐园"

这是主地图**唯一需要警惕的设计风险**。

如果打蔬菜掉的收益接近（甚至高于）闯关，玩家会**赖在主地图刷而不去闯关** ——
核心循环（§2）直接被架空，游戏变成一个站桩打菜的游戏。

**建议规则**：

1. 蔬菜掉落**极少量**账号级素材（比如"菜叶子"，用于解锁装饰性内容）
2. 收益率**显著低于**闯关（建议 1/5 以下）
3. 设**每次进入上限**（比如一次最多掉 20 个），掉满就停
4. **主地图不掉闯关货币、不掉武器** —— 那些必须来自闯关，保住核心循环

**存档归属**：主地图掉落属于**局外永久资源** → 按 §6-Q3 双轨，**归玩家账号**（不归房主）。
这样客人换个车队，自己攒的菜叶子还在。

## 5. 整活互动（等队友时）

| 互动 | 效果 |
|---|---|
| 骑猪 | 骑上冲刺，能撞飞蔬菜（也能撞飞队友） |
| 干草垛 | 可以躲进去，也可以把队友推进去 |
| 水井 | 打水泼人（短暂减速） |
| 风车 | 靠近叶片被拍飞 |
| 语音引菜 | 对着麦克风喊 → 蔬菜被吸引过来（自研语音独门能力，ID-004） |

## 6. 技术要点（几乎不用写新代码）

| 项目 | 做法 |
|---|---|
| **蔬菜实现** | 复用 `EnemyBase` + `Health` + `Telegraph`，新蔬菜 = 新 Prefab + 新 `BulletPattern` 资产，**零新代码** |
| **前摇** | 直接用 `Telegraph`（0.4-0.6s），充能光效打在蔬菜本体上 |
| **弹幕** | 复用 `BulletPattern` SO（扇形 / 单发），弹速建议 14-16（比地牢更慢，主地图以练手为主） |
| **不会倒地** | 蔬菜伤害带 `DamageFlags.NoDown`（`Health` 已支持，见 `DamageInfo.CanDown`） |
| **刷新** | 简单的刷新点 + 计时器，`RoomBehaviour` 用不上（主地图不是房间制） |
| **加载** | **不走 `RoomStreamer`** —— 主地图是单个常驻小场景，直接加载即可 |
| **网络** | 房主权威（Listen Server）：蔬菜状态机、伤害、刷新全在房主；客户端只表现 |
| **存档** | 掉落的"菜叶子"写入**玩家账号存档**（`SaveData` 的解锁区，见 §6-Q3） |

### 6.1 一个需要小改的地方

**番茄的抛物线**：现有 `Projectile` 是**直线匀速**飞行（`_direction * step`），没有重力。
想做"抛番茄"的弧线，需要给 `Projectile` 加一个可选的重力参数。

- 影响面：很小（加一个字段 + `Update` 里累加竖直速度）
- 成本：约 0.5 人天
- **或者**：先用慢速直线弹近似，弧线留到后面做。我建议先直线，别为番茄阻塞进度。
